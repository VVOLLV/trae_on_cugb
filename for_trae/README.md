# TRAE on Campus @ 中国地质大学（北京）

![TRAE on Campus Banner](https://via.placeholder.com/1200x300?text=TRAE+on+Campus+%40+CUGB)

## 🎯 网站目的

本网站是 **TRAE on Campus @ 中国地质大学（北京）** 活动的回顾与复盘平台，旨在：

- 📢 **记录活动历程**：完整呈现从申请、策划到落地、复盘的全流程
- 📊 **展示活动成果**：通过数据和故事展现活动价值
- 💡 **分享经验教训**：为未来校园活动提供参考和借鉴
- 🔗 **建立品牌认知**：向师生展示 TRAE 平台的能力和价值

### 基本信息

| 项目 | 详情 |

3. **落地期**（2026.05.10）：活动现场执行
4. **复盘期**（2026.05.11-15）：总结经验，持续改进

## 🚀 快速开始

### 本地运行

```bash
# 进入项目目录
cd for_trae

# 启动本地服务器
python -m http.server 8000

# 访问网站
open http://localhost:8000
```

### 构建部署

```bash
# 推送代码到 GitHub
git add .
git commit -m "Update content"
git push origin master
```

网站会自动部署到 GitHub Pages。
